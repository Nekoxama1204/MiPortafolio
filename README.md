## 🛠️ Stack Tecnológico

El proyecto fue construido utilizando tecnologías web estándar optimizadas para rendimiento y SEO, desplegado sobre una infraestructura de integración continua.

* **Frontend:**
    * ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) Semántico y accesible.
    * ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) Diseño responsivo adaptado de la plantilla *Ethos*.
    * ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) Interactividad, animaciones (AOS) y manejo del DOM.
    * **Librerías:** jQuery, Modernizr, Slick Slider, PhotoSwipe.

* **Infraestructura & DevOps:**
    * **VCS:** Git & GitHub.
    * **Hosting:** Hostinger (Shared Hosting).
    * **CI/CD:** Despliegue automatizado mediante **GitHub Webhooks** conectados directamente al servidor de Hostinger.
